# Что такое API и как с ним работать

Учебный CLI-проект, который знакомит с понятием API на практических примерах: программа выполняет GET-запросы к публичным API, разбирает JSON-ответы и выводит данные в консоль с цветовым форматированием.

## Возможности

- Выполнение простого GET-запроса к любому URL с выводом статуса, заголовков и тела ответа.
- Получение случайного изображения собаки через [dog.ceo API](https://dog.ceo/dog-api).
- Получение справочной информации о стране через [restcountries.com](https://restcountries.com) (v5, с авторизацией по ключу).
- Те же данные через альтернативный API [countries.dev](https://countries.dev).
- Выборочный запрос только нужных полей (name, capital, population и т.д.).

## Структура проекта

| Файл                  | Назначение                                                                 |
| --------------------- | -------------------------------------------------------------------------- |
| `main.py`             | Интерактивное меню и запуск всех видов запросов.                           |
| `http_client.py`      | Тонкая обёртка над `requests` для GET-запросов.                            |
| `country_info.py`     | Работа с API restcountries.com (авторизация по `RESTCOUNTRIES_API_KEY`).   |
| `country_info_alt.py` | Работа с альтернативным API countries.dev (без ключа).                     |
| `.env.example`        | Шаблон файла окружения с ключом API.                                       |

## Требования

- Python 3.10+
- Пакеты: `requests`, `python-dotenv`, `colorama`

## Установка и запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate  # Linux / macOS

# 2. Установить зависимости
pip install requests python-dotenv colorama

# 3. Настроить ключ API (опционально)
copy .env.example .env      # Windows
# cp .env.example .env      # Linux / macOS
# указать RESTCOUNTRIES_API_KEY в .env

# 4. Запустить
python main.py
```

## Использование

После запуска программа показывает меню. Выберите номер запроса, при необходимости введите URL или название страны, и результат появится в консоли.

> Примечание: если ключ `RESTCOUNTRIES_API_KEY` не задан, restcountries.com использует демо-ключ `rc_live_demo` — ответ будет считаться демонстрационным, реальные данные могут подставляться автоматически.
